Day:08 Javascript Execution Context Visually

These interview notes focus on the fundamental concepts of how JavaScript runs your code, specifically through the lens of Execution Context and the Call Stack.

Lexical

JavaScript determines variable accessibility based on where the code is written, not where the function is called.

Interview Tip: Understanding Execution Context is the "starting point" for mastering more advanced topics like closures, the this keyword, scoping, and the Event Loop
