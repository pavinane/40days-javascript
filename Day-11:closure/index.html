It is a function that has access to its own scope, the outer function's scope, and the global scope. It allows a function to access variables from an enclosing scope or environment even after it leaves the scope in which it was declared.

A closure is when a function remembers and can access variables from its outer lexical scope even after that outer function has finished executing.
