Day:12 - Object

Key point: Object.assign() and the spread operator ({ ...obj1 }) both perform shallow copies, not deep copies.

What is a Shallow Copy?

A shallow copy copies only the first level of an object. Nested objects and arrays are not copied. Instead, their memory reference is copied.

What is a Deep Copy?

A deep copy copies every level of an object. Every nested object and array gets a new memory reference.
